SET UP: attach the repository with the add_repo tool (access "push"), clone it and work in the clone. First remove hand-written rows whose date has passed.

SPLIT RUNS: this is the WEST run. The EAST run covers the Northeast, Mid-Atlantic and South, and also does the artist tour pass for every city. Don't change rows for those cities, except to delete past-dated rows anywhere.
